# Dataset

This project uses the public **Building Data Genome Project 2 (BDG2)** dataset.

The project uses:

- Building metadata
- Hourly electricity consumption
- Weather data

The complete raw dataset is not included in this repository because of its large size.

## Source

Building Data Genome Project 2:

https://github.com/buds-lab/building-data-genome-project-2

## Data Structure

The Power BI project uses three main datasets:

### Building Metadata
Building characteristics such as building ID, floor area, building type and construction year.

### Electricity
Hourly electricity measurements for individual buildings.

### Weather
Weather observations used to compare temperature with electricity consumption.
